# NoveraMP Launcher

Настольный лаунчер NoveraMP на **Rust + Tauri 2 + React + TypeScript** для
Windows x86_64 и Linux x86_64. Интерфейс сделан по предоставленному HTML-макету:
тёмная таблица серверов, фильтры, панель выбранного сервера и отдельные диалоги.

## Возможности

- Собственный заголовок окна: перетаскивание, двойной щелчок для разворачивания,
  кнопки свернуть/развернуть/закрыть. Системная рамка отключена.
- Каталог Arizona RP из
  `https://arizona-ping.react.group/desktop/ping/Arizona/ping.json`, с резервной
  копией последнего успешного ответа.
- Добавление серверов по IPv4/домену, порт по умолчанию 7777; избранное, недавние,
  поиск, фильтры заполненности/пароля/режима/языка, сортировка.
- Настоящие SA-MP UDP-запросы `i`, `c`, `r`: онлайн, пинг, игроки и правила.
  Опрос каждые 30 секунд; отказ в опросе не запрещает подключение.
- Переключатель Arizona для каждого сервера. При включении перед запуском
  отправляется HTTP `GET /` на IPv4 сервера, порт 80, `User-Agent: Arizona PC`.
  Таймаут 3 секунды; неудача не блокирует вход. Движок повторяет подготовку
  соединения и поддерживает свой UDP-пинг.
- Запуск `noveramp --assets <путь> --server <адрес> --nick <ник>`, с
  `--arz-mode` и `--password` при необходимости. Без командной оболочки.
  Пароли серверов не записываются в настройки.
- Автообновление движка перед запуском из `NoveraMP/engine-releases`:
  `noveramp-linux-x86_64.tar.gz` / `noveramp-windows-x86_64.zip`.
- Подписанные обновления самого лаунчера через Tauri Updater из
  `NoveraMP/Launcher/releases/latest/download/latest.json`.
- Настройки папки игровых ресурсов, локального бинарника движка, автообновлений
  и скрытия окна лаунчера. После завершения игры скрытое окно появляется снова.

Игровые ресурсы GTA/Arizona **не скачиваются и не входят в поставку**. При первом
запуске выберите существующую папку игры в настройках. Локальный бинарник движка
можно указать для разработки или до публикации первого engine-релиза.

## Разработка

Нужны Node.js 22, npm и Rust stable (ядро также проверяется с Rust 1.85).
Для Debian/Ubuntu установите зависимости Tauri:

```sh
sudo apt-get install build-essential pkg-config libwebkit2gtk-4.1-dev libgtk-3-dev libayatana-appindicator3-dev librsvg2-dev patchelf
npm ci
npm run tauri -- dev
```

На Windows нужны MSVC Build Tools с C++ toolchain и WebView2 Runtime.

```sh
npm run build
npm test
cargo test --locked -p launcher-core
cargo fmt --all -- --check
```

`npm run dev` открывает только веб-предпросмотр на `http://127.0.0.1:1420`.
В нём настоящий каталог Arizona загружается через Vite proxy, а настройки
предпросмотра сохраняются в localStorage. UDP, процессы и обновления доступны
только в настольном приложении; веб-предпросмотр не имитирует успешный запуск.

Проверки ядра используют локальные TCP/UDP-серверы и временные файлы: протокол
SA-MP, HTTP-заголовки Arizona, аргументы/рабочая папка дочернего процесса,
сохранение настроек, распаковка, контрольные суммы и сохранение старой версии
после неудачного обновления. Для них не нужны игровые ресурсы или живой сервер.

## Обновления движка

Движок и весь его runtime распаковываются во временный каталог. Проверяются
размеры, пути, типы файлов и SHA-256 из GitHub asset digest, если GitHub его
предоставил. Ссылки, абсолютные пути и выход за каталог распаковки запрещены.
После успешной распаковки переключается указатель на новую версию. Предыдущие
версии остаются на диске, работающие бинарники не перезаписываются. Если GitHub
недоступен, используется установленная версия. Если движок ещё не установлен,
ошибка показывается пользователю. Локальный override не обновляется лаунчером.

Данные находятся в системном `app_data_dir` для `com.noveramp.launcher`:
на Linux обычно `~/.local/share/com.noveramp.launcher`, на Windows —
`%APPDATA%/com.noveramp.launcher`. Настройки — `config.json`, журнал движка —
`logs/engine.log`, версии движка — `engine/versions/`.

GitHub-репозитории и файлы релизов должны быть доступны без авторизации;
пользовательские GitHub-токены не встраиваются в приложение.

## CI и релизы Windows / Linux

`.github/workflows/release.yml` проверяет frontend и Rust-ядро, собирает
приложение на `ubuntu-24.04` и `windows-latest`. Обычные push/PR сохраняют
установщики как Actions artifacts. Push тега `v<version>` публикует релиз:

- Windows: NSIS `.exe` и подпись обновления;
- Linux: AppImage, `.deb` и подпись обновления;
- `latest.json` для автоматического обновления обеих платформ.

На Linux автообновление Tauri предназначено для **AppImage**. Для установленного
`.deb` используйте новый пакет. Движок обновляется одинаково в обоих вариантах.

### Ключ подписи

Публичный ключ уже записан в `src-tauri/tauri.conf.json`. Закрытый ключ был
создан локально и хранится **вне репозитория**:
`~/.config/noveramp-launcher/updater.key`. Он создан без пароля. Сохраните его
резервную копию: для обновления уже установленных клиентов нужен этот же ключ.

В **NoveraMP/Launcher → Settings → Secrets and variables → Actions** добавьте:

- `TAURI_SIGNING_PRIVATE_KEY` — содержимое файла `updater.key` целиком;
- `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` — не требуется для текущего ключа без пароля.

Для публикации в этот же репозиторий используется штатный `GITHUB_TOKEN` с
`contents: write`, настроенный в workflow. `ENGINE_RELEASES_TOKEN` из движка
лаунчеру не нужен: он скачивает готовые engine-релизы, а не публикует их.

Перед выпуском обновите версию в `package.json` / `package-lock.json`,
`src-tauri/Cargo.toml` / `Cargo.lock` и `src-tauri/tauri.conf.json`, затем:

```sh
git tag v0.1.0
git push origin v0.1.0
```

Команды выше — пример первого релиза; используйте следующий свободный номер.
Без ключа подписи tagged workflow завершится с понятной ошибкой. Публикация
настоящего релиза и установка обновления на другой машине требуют отдельной
проверки после настройки секрета.

Документация: [Tauri Updater](https://v2.tauri.app/plugin/updater/) и
[GitHub pipeline](https://v2.tauri.app/distribute/pipelines/github/).

Шрифты Golos Text и JetBrains Mono взяты из предоставленного макета и
поставляются с исходной SIL OFL в `public/fonts/LICENSE.txt`.

Иконка NoveraMP предоставлена пользователем. Оригинал — `artwork/icon-source.png`,
PNG/ICO для приложения и установщиков — `src-tauri/icons/`, значки интерфейса —
`public/brand/` и `public/favicon.png`. Варианты подготовлены командой Tauri `icon`
с сохранением прозрачности; изображение не перерисовывалось.
